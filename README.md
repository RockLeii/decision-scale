# Decision Scale V2

Static web app: no backend or build step required.

## Run
Open `index.html` in a modern browser.

## Deploy
Upload the repository to GitHub and connect it to Cloudflare Pages.
Framework: None
Build command: blank
Output directory: `/`

## V2
- Landing page and product positioning
- Decision builder
- 2–4 options
- Custom criteria
- Importance
- Higher/lower-is-better direction
- Confidence
- Weighted normalized results
- Decision drivers
- Sensitivity / what-if checks
- Shareable URL
- Responsive layout
